# ?? Spotify Live Wrap`n`n**Your personal Spotify Wrapped, but in real-time. Forever.**`n`nSpotify Live Wrap is a high-performance desktop application designed to track every single second of your Spotify listening habits. Unlike the official Wrapped that only looks at the year, Live Wrap builds a permanent, local archive of your musical journey.`n`n## ? Key Features`n`n- ?? **Precision Tracking**: Not just "played", but "listened". The app calculates the exact duration of every song, accounting for pauses and skips.`n- ?? **Live Analytics**: A stunning React dashboard that updates every 15 seconds, giving you an immediate view of your total listening time and top tracks.`n- ??? **Local-First Storage**: Your data stays yours. Everything is stored in a local SQLite database on your machine.`n- ?? **Seamless Authentication**: Implements OAuth 2.0 PKCE for secure login, with tokens stored safely in the Windows Credential Manager.`n- ?? **Visual Insights**: Interactive charts showing your daily listening activity and top-played songs.`n`n## ??? Technical Architecture`n`n- **Frontend**: React 18 + Vite + Tailwind CSS + Recharts`n- **Runtime**: Electron`n- **Backend**: Node.js (CommonJS)`n- **Data**: SQLite3`n- **Auth**: Spotify Web API (PKCE Flow)`n`n## ?? Getting Started`n`n### Prerequisites`n- Node.js (LTS)`n- A Spotify Developer Account ([developer.spotify.com](https://developer.spotify.com))`n`n### Installation`n`n1. **Clone the repo**`n   \`git clone https://github.com/yourusername/spotify-live-wrap.git\``n   \`cd spotify-live-wrap\``n`n2. **Install dependencies**`n   \`npm install\``n`n3. **Environment Setup**`n   Create a `.env` file in the root directory:`n   \`SPOTIFY_CLIENT_ID=your_client_id_here\``n   \`SPOTIFY_REDIRECT_URI=http://127.0.0.1:8888/callback\``n`n4. **Launch**`n   \`npm start\``n`n## ??? Security`nTokens are never stored in plain text. The app utilizes the `keytar` library to interface with the Windows Vault, ensuring your Spotify credentials are encrypted and secure.`n`n---`n`n*Built for music lovers who want to own their data.*
